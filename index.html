How the language works. None of these chatbots let a link set the reply language, so the instruction is added to the question itself. Google AI Mode also gets hl= so its own buttons and labels come up in the same language.

How the link works. The question is packed into the part after the #, so it never reaches a server — not even yours. This whole thing is one static file with no backend.

About Gemini. Google's Gemini app ignores prompts passed in a URL. Google AI Mode runs on Gemini and does accept them, so that's the default. If you pick the Gemini app anyway, the link copies the question to their clipboard and they paste it.
