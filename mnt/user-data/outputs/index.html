Prefill a prompt with a URL

You want to send someone a link that opens an AI chatbot with the question already asked. Most of them support it. Two of the biggest don't, and neither says so.

Last verified 4 September 2026. None of these parameters are officially documented, so any of them can change without notice.

Every format below is the same idea: put the question in the query string, URL-encode it, and the chatbot opens with the prompt loaded. What differs is whether it also submits the prompt, and whether the parameter is honoured at all.

Test links carry a harmless sample question. Signed-out behaviour can differ from signed-in.

Gemini ignores the prompt. AI Mode doesn't.

This is the one that costs people an afternoon. Search for a way to prefill Gemini and you will find plenty of gemini.google.com/app?q=… links being passed around. Open one and Gemini loads with an empty box. The question is simply dropped.

Nothing you add to the URL fixes it. The links that appear to work belong to people running a browser extension that fills the box on their behalf, which does nothing for anyone you send the link to. Several tooling authors have resorted to simulated keystrokes and clipboard automation for exactly this reason.

The workaround isn't a workaround at all. Google AI Mode runs on Gemini and does accept a prompt in the URL. Same model, and the link actually works:

https://www.google.com/search?udm=50&aep=11&q=YOUR+PROMPT

The udm=50 parameter is what routes a query to AI Mode rather than ordinary search results. If you'd rather not remember it, google.com/ai resolves to the same place.

Setting the interface language

Add &hl=hi — or ta, bn, mr, and so on — and Google's own labels and follow-up suggestions come back in that language. It does not reliably control the language the model answers in. For that, put the instruction in the prompt itself; no chatbot on this list has a URL parameter for response language.

Microsoft quietly switched Copilot off

Copilot used to honour ?q=, which let people wire it up as a browser search engine. That stopped working in late 2025: the parameter still loads the page, but the text appears only as a heading and the chat box stays empty, breaking the search-engine integration that Firefox derivatives relied on.

The reason is security rather than neglect. A prefill parameter that auto-runs is an attractive attack surface — a link arrives, gets clicked, and the model receives attacker-supplied instructions before the user has typed anything. Microsoft disabled the parameter without a public announcement after researchers demonstrated exactly that against Copilot.

The security problem with all of these

It's worth being clear-eyed, because this affects every working format in the table. Researchers have named the general pattern parameter-to-prompt injection: because these query parameters accept natural language rather than plain search terms, a crafted link can feed instructions straight to a model that has access to the recipient's data. The same class of flaw has turned up in Perplexity's Comet browser and in Microsoft 365 Copilot's enterprise search.

What this means in practice. Treat a prompt link the way you'd treat any link: fine from someone you know, worth reading before you tap from someone you don't. The whole prompt is visible in the URL, so you can always see what it's about to ask before you open it.

Getting the encoding right

  • Encode the whole prompt. In JavaScript that's encodeURIComponent(text). Spaces, question marks, ampersands and apostrophes all break the URL otherwise, and an unescaped & silently truncates your prompt.
  • Keep it under about 2,000 characters. There's no published limit, but browsers and CDNs start dropping long URLs somewhere past that.
  • Non-Latin scripts are fine. Hindi, Tamil and Arabic all survive percent-encoding as UTF-8. They inflate the URL roughly threefold, which matters against the length ceiling.
  • Newlines work. They encode as %0A and survive on every service in the table, so multi-line prompts are fine.
  • Mobile is the fragile part. A tap on these links can be intercepted by an installed native app, which may not honour the query string the way the website does. Test on a phone, not just a desktop.

Why the formats drift

None of this is documented by any of the vendors. Every parameter here was found by inspection, and Copilot is a live demonstration that a working format can be withdrawn overnight with no changelog. If you're building anything that depends on one, re-test it periodically and keep a fallback that copies the prompt to the clipboard instead.
